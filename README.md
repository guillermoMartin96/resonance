# StemForge (working title)

AI-assisted audio extraction and remix workstation. **Product priority: recover and reuse actual audio from authorized recordings**, not approximate/recreate it with synthesis.

Status: pre-implementation. Name is provisional. Browser-first, local-file-first, audio-first.

## Start here
1. Read `CLAUDE.md` and `docs/PRODUCT.md`.
2. Follow `docs/ENGINEERING_PLAYBOOK.md`.
3. Complete the research gates in `docs/research/RESEARCH_GATES.md` before selecting a separator.
4. Execute `docs/milestones/M1.md` only after the research decision is recorded.

This app is distinct from JamRecall and the spacecraft simulator; keep repositories and dependencies separate.
