# StemForge (working title)

AI-assisted audio extraction and remix workstation. **Product priority: recover and reuse actual audio from authorized recordings**, not approximate/recreate it with synthesis.

Status: M0 research on `feature/m0-research` (see `docs/proof/M0-proof.md`). Decisions approved 2026-10-09: DR-0001 (provisional engines: Demucs `htdemucs` + optional MDX `Kim_Vocal_2`, non-commercial use only; no-ML baseline is the M1 default), DR-0002 (corpus expansion, not yet acquired), DR-0003 (native Intel macOS CPU, pinned, Node 22 LTS). Blind listening gate pending owner results. Pre-implementation. Name is provisional. Browser-first, local-file-first, audio-first.

## Start here
