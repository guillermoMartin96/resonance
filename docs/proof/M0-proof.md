## Failures and limitations
- `pip install demucs==4.1.0` fails on Intel macOS (sphn → Rust build); worked around with `--no-deps`.
- python-audio-separator (current) is not installable on Intel macOS; 0.21.2 needs numba pins + ffmpeg and has a stem-normalisation bug.
- BabySlakh download was interrupted once (curl exit 18) and was resumed; md5 verified.
- ccMixter a cappellas: HTTP 403 for unauthenticated downloads. Path stopped, not worked around.
- Wikimedia returned HTTP 429 once; fetch script now honours Retry-After.
- Procedural fixture levels were rebalanced after the first dev run ("other" sat −21 dB in the mix); holdout seeds had never been run.
- BabySlakh Track00017 excluded by the loader's existing completeness rule (missing bass stem file).
- First perf probe run discarded: fixture generation in the child process inflated peak RSS; rerun with a pre-written WAV.
- No subjective listening performed; small n; 16 kHz material; single CPU machine. See evaluation §6.
