# Milestone roadmap

- **M0 — Research gates:** environment audit, rights/terms review, benchmark corpus and separator comparison; decision request.
- **M1 — First vertical slice:** authorized file import, background separation, stem playback and A/B, job status, provenance, basic tests.
- **M2 — Sample extraction:** region selection, trimming, clip library, WAV exports and provenance sidecars.
- **M3 — Remix workspace:** multitrack timeline, clip placement, tempo-aware alignment, mix preview/export.
- **M4 — Deeper isolation:** percussive sub-stems, quality controls, source-aware search, optional AI assistance.
- **M5 — Licensed discovery:** sample-library connectors, license filters, attribution and export policy checks.

Each milestone requires a proof record, review and explicit go/no-go.
