# DR-0001 — Separation engine selection

Status: OPEN — research required; no engine approved.

## Decision
Select an initial separation backend based on legal use, fidelity, runtime and developer compatibility.

## Options
A. Demucs-family candidate (verify current package and weights license)
B. MDX/UVR-compatible candidate (verify implementation and model-specific licenses)
C. Other evaluated model with equivalent evidence

## Evidence needed
R1 environment inventory; R2 model/license matrix; R3 reproducible benchmark; R4 listening rubric and measurements.

## Recommendation
Pending evidence. Favor the simplest legally usable model meeting minimum audible quality on the target machine, behind an adapter.

## Approval
Tech lead selects an option after review. No silent commitment.
